# 🔬 Autonomous AI Research Agent

> An end-to-end multi-agent system built with **LangGraph**, **RAG**, and **FastAPI** that dynamically searches, analyzes, and synthesizes academic literature into structured reports.

---

## 📌 Overview
Standard LLMs struggle with static knowledge limits and shallow academic analysis. This autonomous agent pipeline receives a high-level research prompt, breaks it down into search strategies, retrieves papers via open APIs (ArXiv/Semantic Scholar), performs RAG-based context extraction on full PDFs, and outputs a publication-ready Markdown report.
